In/Out Help

Welcome to In/Out

Review videos, find the moments you need, and export finished clips without leaving the timeline.

The four tools

  • Clip is the main workspace for playback, trimming, transcripts, markers, AI Suggestions, and clip export.
  • Analyze checks the video for black frames, possible bad edits, silent gaps, and profanity.
  • Convert exports the complete video as video or audio without requiring an In/Out selection.
  • Inspect shows file, stream, color, bitrate, and audio/video timing information.
#

System requirements

  • macOS 14 Sonoma or later.
  • A Mac with Apple silicon.
Note

Apple Intelligence requires a supported Mac, macOS 26 or later, and Apple Intelligence enabled in System Settings. Cloud AI providers require their own API keys.

In/Out Help

Open or download videos

Open a local file or download a video directly from a supported URL.

Open a file

  1. Choose File > Choose Media…, drag a video or audio file into the window, or open a file with In/Out from Finder.
  2. Begin working as soon as the player and timeline appear. The waveform and thumbnails can continue loading in the background.
#

Download from a URL

  1. Choose File > Download Media from URL…, or paste a URL into the opening screen.
  2. Open More Options if you want to change quality, save location, or authentication.
  3. Choose Download. In/Out opens the result when the download finishes.
Note

Best Compatible is recommended for immediate playback. Best Available may take longer because incompatible video is converted to MP4.

#

Browser cookies and multiple videos

  • Choose Use Browser Cookies when a site requires your existing signed-in browser session, then select the browser to use.
  • If a URL produces several video files, In/Out lets you choose one result or open all of them in separate windows.
  • The first URL download may install managed helper tools. In/Out maintains these tools separately from command-line copies on your Mac.

In/Out Help

Trim and navigate

Set an accurate range, move quickly through the video, and keep useful moments marked.

Choose a clip

  1. Move the playhead to the beginning and press I to set the In point.
  2. Move to the end and press O to set the Out point.
  3. Drag either edge of the selection in the timeline for a visual adjustment.
Note

Press X to clear the selection. Press ⌘ A to select the complete video.

#

Playback and zoom

  • Press Space to play or pause. Use J, K, and L for shuttle playback.
  • Press ← or → for precise, one-frame adjustments.
  • Hold ⇧ with ← or → to move 10 frames at a time.
  • Hold ⌥ and ⇧ with ← or → to move 100 frames at a time.
  • Use ⌃ Space to play only the current In/Out selection.
  • Use the zoom controls or keyboard zoom shortcuts to inspect detail or fit the complete timeline.
  • Drag the divider below the player to resize it. Double-click the divider to toggle its preferred and maximum heights.
#

Markers and frame capture

  • Press M to add a marker at the playhead.
  • Use ↑ and ↓ to visit In/Out points, regular markers, AI suggestion markers, and the boundaries of suggested ranges.
  • Press Delete or Backspace to remove the selected regular marker.
  • Choose Capture Frame to save a PNG image of the frame at the playhead.

Work with transcripts

Generate, search, format, select, copy, and export time-aligned transcript text.

Generate a transcript

Open the transcript sidebar in Clip, then choose Generate Transcript. In/Out uses Parakeet for fast, word-timed transcription. Starting AI Suggestions before a transcript exists can generate it automatically first.

Note

Wording and timing can move slightly while transcription is still in progress.

#

Read and navigate

  • Use the transcript View popover to switch between Compact Lines and Paragraphs, show or hide timecodes, and change text size.
  • Choose View > Timecode Format to change timecodes throughout the app. Manage built-in and custom presets in the Timecodes section of Settings.
  • Search for a word or phrase, then use the previous and next controls to move through matches.
  • Click a transcript row to move the playhead. Double-click a row to begin playback there.
  • During playback, the transcript follows the active row. Hiding the sidebar leaves the transcript available in the current window.
#

Select and copy text

  • ⌘-click rows to add or remove individual rows from the selection.
  • ⇧-click to select a continuous range of rows.
  • Press ⌘ C to copy the selected rows. Right-click a selected row to copy the selection, or an unselected row to copy only that row.
  • Press Escape or click below the transcript rows to clear the selection.
  • Copied rows include timecodes only when timecodes are visible.
#

Export a transcript

  • Choose Export in the transcript sidebar to select Text, Markdown, CSV, JSON, SRT, or WebVTT.
  • Text and Markdown support Paragraphs, Compact Lines, or Continuous Text.
  • Readable exports can omit timecodes or include start times or start-and-end times. Continuous Text never includes timecodes.
#

Reopen saved transcripts

Completed transcripts are stored locally without copying the original video. Opening the same unchanged file restores its transcript automatically.

  • Use Recent Transcripts on the opening screen or File > Open Recent Transcript to reopen a video with saved transcript data.
  • Pin an entry to prevent automatic removal. Missing files can be located again from the entry's contextual menu.
  • Settings > General controls transcript retention and provides Clear History. Modified video is treated as a different file and is transcribed again.

Use AI Suggestions

Ask freeform questions or run reusable tasks that produce text, markers, or timeline ranges.

Choose a provider

Open Settings > AI to choose Apple Intelligence, OpenAI, Claude, or Gemini. Cloud providers require an API key and send transcript text directly to that provider. API usage is separate from consumer chat subscriptions.

#

Freeform

  1. Choose AI Suggestions in Clip, then select Freeform.
  2. Ask a question or describe the text you want, and choose Selected Clip or Entire Video.
  3. Choose Ask AI. The response opens as a text result that you can copy or refine.
#

Preset Tasks

Preset Tasks includes Topic Changes, Highlights, Ad Breaks, Notable Excerpts, YouTube Chapters, and any custom tasks you create in Settings > AI. A task can return markers, ranges, a timestamped list, or a standalone document.

  • Only one request runs at a time, but completed results remain in separate closable tabs.
  • Use the refinement field below a result to ask questions or request changes. Text results retain browsable version history.
  • Settings > AI lets you hide built-in tasks and create reusable custom tasks with your own instructions and output type.
#

Use results with the timeline

  • Only the active result tab places its markers or ranges on the timeline.
  • Click a suggestion row to seek; double-click it to begin playback at that result.
  • Click a suggested range in the timeline to seek to its start. Double-click it to make the range the current In/Out selection.
  • Use ↑ and ↓ to navigate suggestion markers and both ends of suggested ranges.
  • Text documents do not add timeline decorations. Use Copy Text to place the finished text on the clipboard.

Analyze videos

Run technical checks for visual, audio, timing, and transcript-based problems.

Available checks

  • Detect black frames finds sustained sections where most of the image is black.
  • Detect possible bad edits checks for brief visual interruptions, suspiciously short shots, frozen video, abrupt audio discontinuities, clipped audio at edit points, timing gaps, decode problems, and mismatched stream endings.
  • Detect silent audio gaps finds silence longer than the duration shown beside the option.
  • Detect profanity uses the video transcript to locate potentially profane words.
#

Run and review

  1. Open Analyze and enable the checks you need.
  2. Choose Run Analysis. Full video or audio scans can take time on long files.
  3. Click a result to seek to it, or double-click to play it with context.
Note

Results are review candidates, not definitive errors. Confirm each result in the player before making an editorial decision.

In/Out Help

Export and convert

Export a selected clip quickly, re-encode it with precise options, or convert the complete video.

Clip export modes

  • Fast uses stream passthrough with minimal processing and no re-encoding. Choose a compatible container and export quickly.
  • Advanced re-encodes the clip and provides container, video codec, resolution, bitrate, audio, caption, and processing options.
  • Audio Only exports the selected range as an audio file with format and audio-processing options.
#

Export or queue

Choose Export Clip to select a destination. ⌥-click Export Clip, or use Quick Export Clip, to use the configured automatic destination without a save dialog. If another job is running, the export button adds the clip to that window's queue.

#

Burned captions

Advanced video export can generate and burn captions into the exported image. Caption appearance can be selected in the export options or set as a default in Settings.

#

Change the frame

Open Framing in Advanced video export to choose an output aspect ratio. Fit keeps the complete picture, Fill crops the edges, and Blur keeps the complete picture over a blurred background. With Fill selected, drag the preview for a custom crop or double-click it to return to center. The same framing options are available for clips and complete-video conversion.

#

Convert the complete video

Use Convert when you need the complete file rather than the current In/Out selection. Video uses the same options as Advanced clip export; Audio Only uses the same options as Audio Only clip export.

Inspect videos

Review technical details about a video without running a separate analysis.

What Inspect shows

  • The technical summary lists the primary video, audio, and timing characteristics at a glance.
  • Video details include stream count, codec, resolution, frame rate, bitrate, color primaries, and transfer function.
  • Audio details include stream count, codec, sample rate, channel layout, and bitrate.
  • Container details include duration, overall bitrate, file size, and container type.
  • Timing compares the playable start, duration, and end of the first video and audio streams and calls out meaningful offsets.
#

File and console

  • Choose Show in Finder to locate the source, or right-click its icon to copy the path.
  • Open Console to review output from helper tools. You can copy or clear the console when troubleshooting.

Install and update

Install In/Out once, then let the built-in updater install new releases in place.

Install In/Out

  1. Open the downloaded In-Out DMG file.
  2. Drag In-Out.app onto the Applications folder shown in the installer window.
  3. Open In/Out from Applications. You can eject the installer disk image afterward.
#

Install an update

  1. Choose In/Out > Check for Updates. In/Out also checks automatically when it opens.
  2. When an update is available, choose Install Update.
  3. In/Out downloads, installs, and relaunches the new version automatically.
Note

Updating from a version installed before in-place updates were introduced may require one final DMG installation.

In/Out Help

Managed components

Learn about the helper tools In/Out uses for downloads, exports, analysis, and transcription.

Included and managed tools

  • ffmpeg and ffprobe handle export, conversion, video scanning, and inspection.
  • Managed Python, yt-dlp, and Deno handle supported URL downloads.
  • Parakeet provides fast, word-timed transcripts for the Clip sidebar, AI Suggestions, profanity detection, and generated burned captions.
#

Check or repair tools

Open Settings > Tools to check tool availability. Downloader controls can check for updates, repair the managed downloader, or roll back to the previous yt-dlp version. In/Out isolates app-managed downloads from personal yt-dlp and Python configuration.

Note

When reporting a helper-tool problem, open Inspect > Console and include the relevant error text.
