What you can do

Practical tools for working through media

In/Out is designed for producers, journalists, researchers, and anyone who regularly turns long recordings into useful clips and text.

Clip

Make precise clips without project setup

Use thumbnails, a waveform, zoom, markers, and familiar In/Out controls to isolate the exact range you want.

  • Quick or advanced video export
  • Audio-only export and export queues
  • Frame capture and marker navigation

Transcript

Find what was said, not just where it happened

Generate a fast local transcript, search it, follow along with playback, and click any passage to jump to that moment.

  • Compact lines or readable paragraphs
  • Optional timecodes and adjustable text size
  • Copy passages or export Text, Markdown, CSV, JSON, SRT, and WebVTT

AI Suggestions

Turn analysis into something you can use

Find highlights, topic changes, possible ad breaks, clip-worthy ranges, YouTube chapters, or written descriptions.

  • Suggestions stay linked to the media timeline
  • Create custom analysis recipes
  • Refine results and revisit earlier versions

Optional. Choose a supported AI provider in Settings; cloud providers require your own API key.

Convert

Prepare complete files for the next step

Convert the full source to a new video or audio file using the same advanced controls available for clips.

  • Video format, codec, resolution, and bitrate
  • MP3, M4A, WAV, and audio processing options
  • Burned captions when you need them

Analyze

Catch common problems before delivery

Scan media for black frames, silence gaps, and profanity, then jump directly to each result for review.

Open & Inspect

Bring media in and understand what you have

Download supported online media, use browser authentication when needed, and inspect codecs, resolution, frame rate, bitrate, audio, and container details.

Purposefully focused

Common media work without a full editing project

In/Out is not trying to replace a nonlinear editor. It is for the work before and around editing: reviewing a long source, finding a quote, pulling a clean clip, making a transcript, converting a file, or checking media before it goes somewhere else.

Requirements & privacy

Built for current Macs

  • macOS 13 Ventura or later
  • Apple silicon Mac

Your transcription can stay local

Standard transcript generation runs on your Mac. AI Suggestions are optional. If you choose a cloud AI provider, In/Out sends the analysis request to that provider and stores your API key in macOS Keychain.

Download

Install In/Out on your Mac

The download is a notarized macOS installer served directly from the latest GitHub release.

Download In/Out for macOS
  1. Download and open the DMG.
  2. Drag In/Out into the Applications folder shown in the installer.
  3. Open In/Out from Applications.

For updates, choose Check for Updates in the app. In/Out downloads and opens the new installer; drag it into Applications and choose Replace.
