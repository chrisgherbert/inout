## Install In/Out

1. Open the downloaded In-Out DMG file.
2. Drag In-Out.app onto the Applications folder shown in the installer window.
3. Open In/Out from Applications. You can eject the installer disk image afterward.

## Install an update

1. Choose In/Out > Check for Updates. In/Out also checks automatically when it opens.
2. When an update is available, choose Install Update.
3. In/Out downloads, installs, and relaunches the new version automatically.

> **Note:** Updating from a version installed before in-place updates were introduced may require one final DMG installation.
