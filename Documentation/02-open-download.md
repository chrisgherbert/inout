## Open a file

1. Choose File > Choose Media…, drag a video or audio file into the window, or open a file with In/Out from Finder.
2. Begin working as soon as the player and timeline appear. The waveform and thumbnails can continue loading in the background.

## Download from a URL

1. Choose File > Download Media from URL…, or paste a URL into the opening screen.
2. Open More Options if you want to change quality, save location, or authentication.
3. Choose Download. In/Out opens the result when the download finishes.

> **Note:** Best Compatible is recommended for immediate playback. Best Available may take longer because incompatible video is converted to MP4.

## Browser cookies and multiple videos

- Choose Use Browser Cookies when a site requires your existing signed-in browser session, then select the browser to use.
- If a URL produces several video files, In/Out lets you choose one result or open all of them in separate windows.
- The first URL download may install managed helper tools. In/Out maintains these tools separately from command-line copies on your Mac.
