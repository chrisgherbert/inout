# What’s New

## More Consistent Sounds and Notifications

- Video downloads now provide audible feedback when they finish.
- Fast, advanced, audio, transcript, and analysis tasks now use consistent completion feedback.
- Background tasks use macOS notifications, while active windows use the selected completion sound without a duplicate notification.
- Replaced the unavailable Crystal sound with Glass and removed redundant sounds from quick transcript exports.
- Cancelled tasks no longer produce unnecessary completion notifications.
