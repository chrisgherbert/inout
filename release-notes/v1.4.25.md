# What’s New

## Faster URL Downloads

- URL downloads using browser cookies now start significantly faster, especially with larger browser profiles.
- Improved preparation status shows what In/Out is doing before downloading begins.
- The download console is now available before a video finishes loading.

## Other Improvements

- Improved compatibility and consistency of the app-managed download tools. Homebrew and system-installed tools are not required.
- Fixed an issue that could open multiple blank windows at launch.
